IMPOSTAZIONI

Il riconoscimento vocale usa la Web Speech API del browser (gratuita, funziona meglio su Chrome/Edge sia desktop che Android). Le risposte vengono generate chiamando l'API di Groq: inserisci qui la tua chiave (creala gratis su console.groq.com). La chiave resta salvata sul dispositivo (localStorage del browser) e viene inviata solo alle API di Groq.

Su Android: ospita questi file (index.html, manifest.json, sw.js, icon-192.png, icon-512.png) su un sito HTTPS (es. GitHub Pages), apri il sito in Chrome e scegli "Aggiungi a schermata Home". Una volta installata, l'app si apre a schermo intero come una vera app, il permesso microfono resta valido stabilmente e la chiave API non si perde più tra un avvio e l'altro.

Browser senza riconoscimento vocale (es. Samsung Internet, Firefox Android): usa il campo di testo in basso per scrivere a JARVIS, la risposta vocale funziona comunque.

In ascolto continuo, l'app richiede il "wake lock" per evitare che lo schermo si spenga durante l'attesa della parola d'attivazione.
